# Brand files

Put approved brand images here and point the brand file at them, for example:

- `dr-halima-logo.png` → `"logo_path": "brands/assets/dr-halima-logo.png"` (transparent PNG works best)
- `dr-halima-portrait.jpg` → `"person": { "photo_path": "brands/assets/dr-halima-portrait.jpg", "photo_approved": true }`

Only add a photograph of a person with their permission. The pipeline never generates an AI face for her.
